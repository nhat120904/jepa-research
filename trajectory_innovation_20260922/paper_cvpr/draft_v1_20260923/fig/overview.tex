\caption{\textbf{Conditional Trajectory Abstraction.}
\emph{Top:} at each decision, the history is encoded once into a context $C$, and a frozen policy proposes $K$ action chunks.
The world model predicts, for each chunk, a short discrete code $\hat S$ of the chunk's entire future segment, conditioned on $C$.
A reader that sees $C$ and the code, but never the action, answers queries such as the remaining steps to a goal image.
Since codes do not depend on the query, one prediction per candidate serves any number of goals.
\emph{Bottom:} during training, a source encoder compresses the actual future segment into the code, the reader is trained on self-supervised query targets computed from frozen features of that future, and the world model learns to predict the code; code and world model are co-designed for query retention, rate, and predictability.}
\label{fig:overview}
