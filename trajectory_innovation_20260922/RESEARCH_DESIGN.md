# Conditional trajectory abstraction: a falsifiable method proposal

2026-09-22. Proposed architecture and experiments; efficacy and novelty unconfirmed.

## 1. What the closed experiments actually constrain

Wall 53750 trained with 24 independent training prefixes, eight proposal-linked
queries, custom predictors, one seed, and repeatedly inspected validation. It showed
poor generalization for summary, frame-token and direct models. It supports stopping
that implementation. It does not identify compression as the unique cause, establish
a data scaling law, or evaluate a full published DINO-WM baseline.

An additional existing audit matters: order-jepa/RUN_STATUS.md reports that the
original DINO-WM PushT checkpoint achieved .365 witness-free selection success with
both predicted and encoded real futures. The dynamics-excess regret CI includes zero.
That particular candidate/goal/cost setup offers no established predictor-specific
decision headroom. Reusing its task name cannot undo that finding.

The proposed change therefore has three inseparable implementation prerequisites:
an explicit conditional code, sufficient independent data, and an independently
qualified policy/candidate/scorer interface. No architecture guarantees a positive result.

## 2. Borrowed principle and potential contribution

[Deep Contextual Video Compression, NeurIPS 2021](https://papers.neurips.cc/paper_files/paper/2021/hash/96b250a90d3cf0868c83f8c965142d2a-Abstract.html)
uses learned context at encoder and decoder to improve video coding. It specifically
motivates conditional coding beyond simple pixel-residual subtraction.

Our hypothesis: history C already contains scene layout and current appearance. A
future code should spend its limited capacity on the information about a proposed
segment needed to answer future queries given C. The reader should reuse C explicitly.
This is a conditional compression hypothesis; it does not require hidden task state.

This differs from merely providing history to the predictor. In the final Wall model,
the summary reader receives summary and query; scene information must traverse that
bottleneck. Here the decoder receives the same cached observed context as every
matched baseline. No multiplication of a single-context cache by K candidates when
reporting memory, and no pretending the context costs nothing in end-to-end latency.

Potential method contribution: **co-design a conditional segment code for both
query retention and action-conditioned predictability**, demonstrating a better
distortion/compute frontier and downstream benefit on supported action candidates.
Neither conditional coding, the rate-distortion principle, quantization, JEPA,
probabilistic prediction nor query-based sufficiency is a new contribution by itself.

## 3. Formal object

Let h be observed history (images plus permitted agent proprioception), A an ordered
unexecuted action chunk, tau the future observations generated by executing A, and
C=E(h) a cached representation. C uses only present/past information.

For a fixed family of queries Q, define y_q=Psi_q(E(tau)). A conditional trajectory
code S must allow D(C,S,q) to recover y_q. The source encoder q_phi(S|C,tau) sees the
real future only during training. The world model p_theta(S|C,A) predicts the code
before execution. The reader receives no raw candidate actions.

An idealized objective is conditional rate-distortion:

    minimize E[d_Q(D(C,S), y)] subject to I(tau; S | C) <= R.

This is a research formulation, not a newly proved theorem. Using C in both encoder
and decoder makes this conditional coding; do not call it the exact Wyner-Ziv setting
in which side information is available only at the decoder.

Use discrete codes for a concrete budget: M in {8,16,32}, vocabulary V=256,
nominal maximum code length M log2(V) = {64,128,256} bits per future segment.
These numbers count code indices ONLY. Expanded embeddings, codebooks, decoder,
context cache and intermediate tensors are separately reported. At first no actual
entropy coder is implemented, so learned cross-entropy is a rate surrogate.

Do not measure compression using KL(q(S|C,tau) || p(S|C,A)) alone: that is a
predictability mismatch and need not measure stored/transmitted bits. A separate
context-only entropy model r_omega(S|C) can estimate rate; the finite code budget
already gives an explicit upper bound on index storage.

## 4. Architecture

### Observation and history

Use a frozen self-supervised spatial encoder, initially DINOv2 ViT-S/14 to align with
the original DINO-WM reference. Keep its patch grid until a separate spatial pooling
control establishes retention. All arms see identical image history/proprioception.
Cache history once; do not train a VLA or language encoder.

### Conditional future encoder, training only

Future patch tokens receive spatial and native-time positions. M learned segment
queries cross-attend to those tokens and C; quantization produces S. Decoder D
cross-attends to C and S to answer a typed visual-temporal query. A learned conditional
representation is preferred to hard-coded subtraction of current/future features.

S represents a full segment at a specified temporal resolution. It is not simply M
codes per frame. A per-frame code with the same context and total bit budget is the
critical control. A trajectory code should not be promised to answer arbitrary
frame-reconstruction queries at arbitrary resolution.

### Action-conditioned predictor: this is the world model

Given C, the chronological chunk A and horizon, a modest Transformer predicts S.
Use autoregressive categorical prediction across the short code sequence initially,
so dependence among code positions is retained. M code-generation steps are not
automatically faster than H frame predictions; latency must be measured.

The predictor does not receive future images, future proprioception, contact labels,
success labels, or the query. D(C,S,q) supports reuse for new queries without running
the predictor again. A direct model D_direct(C,A,q) is a required strong baseline.

### Joint training, and why it differs from frozen arbitrary targets

1. Warm-start the source codec/readout on observed future features and sampled queries.
2. Train p_theta to predict stopped-gradient source codes from C,A.
3. Alternate a fixed, predeclared number of source-code and predictor updates. The
   source-code objective includes query distortion, a rate term, and predictability
   under a frozen copy of p_theta. The predictor learns from fixed teacher codes for
   each update block. An EMA target copy stabilizes targets but is not credited as new.

Symbolically, an alternating source loss is:

    L_source = D_Q + beta E[-log r_omega(S|C)]
                    + lambda E[-log stopgrad(p_theta)(S|C,A)].

Predictor loss is cross-entropy against stopgrad(source codes). Straight-through
quantization/relaxation is an estimator, not a differentiable discrete identity.
Anchor the codec by nonconstant future-feature query targets, and measure code use,
history-only performance and within-prefix action distinctions. A variance/entropy
regularizer alone does not prove the code preserves the right information.

The lambda=0 matched ablation is essential: it tests whether making the code easier
to predict adds anything beyond conditional query compression. Other controls share
the same data, auxiliary losses, optimizer budget and decoder capacity where possible.

Distributional prediction is supported by the categorical prior, but uncertainty is
not the explanation assumed for Wall's failure. Average the ANSWERS of code samples,
not code embeddings before a nonlinear decoder. Deterministic direct query prediction
can already estimate conditional expected answers; sampling must earn its extra cost.
Begin with deterministic MAP and four samples as a predeclared calibration/compute
comparison. Sampling only represents uncertainty usefully if held-out calibration works.

## 5. Fully self-supervised scope

Learn from image/action sequences and permitted agent proprioception. No simulator
contact/pose/coverage labels, native rewards, human event annotations or success
labels enter WM, codec or query-reader training. The frozen proposal policy is a
separate pretrained imitation-learning asset; using it does not make the WHOLE stack
expert-free. State this explicitly in any paper.

Targets come from the frozen SSL feature space and sampled query parameters:

- feature evidence in a bounded time interval;
- temporal average and maximum similarity to an independently chosen image anchor;
- evidence for anchor u followed by v, at a declared temporal resolution;
- masked local spatial feature probes to preserve fine motion information.

Use frozen feature kernels and train-only scales, not a red-object centroid or a
contact monitor. Train with positive/hard-negative queries drawn from data and report
their construction. For validation/control, anchors and windows are fixed independently
of the candidate whose future is scored. Split by root trajectory before any window,
anchor bank, normalization, or target learning. Freeze query family and weighting
before outcome-based qualification; no retuning the kernel to physical success.

Image-derived queries have design assumptions; self-supervised does not imply a
universal task metric. Actual-future query scores must first pass the physical-cost
qualification in EXPERIMENT_CONTRACT.md. If they fail, this control use of the query
family is unqualified, even if the codec reconstructs it perfectly.

### 5a. Amendment (2026-09-23, user decision): task-reward labels allowed for the reader only

Evidence behind the change:
- Gate C: the fixed SSL query score failed on actual futures (+3 pp against oracle +15 pp).
- C2 / C2-confirm: a label-free hindsight reader did not replicate.
- S1: the label-free sibling-contrast reader did not train, because sibling futures converge within 16 policy steps.
  A reader trained on the task's own dense reward (PushT coverage) resolved siblings offline (retained gap 0.55).

The user chose to relax §5, **for the query reader D only**:

- **Allowed for training D:** task reward/progress labels computed by the simulator, and success labels. For PushT this is coverage (the env's reward basis). For LIBERO it is BDDL goal progress and success.
  This matches GPC-RANK (learned reward predictor) and V-GPS (offline-RL value).
- **Still forbidden:**
  - labels in the WM or codec objectives. The code S stays self-supervised apart from the reader's distortion term, which is now task-aware.
  - any label at test time. D sees only C, S (or actual future features in actual-future gates) and the goal image.
- **Consequences for the paper:**
  - The "fully self-supervised" claim is dropped.
  - The contribution rests on the conditional compact code and predict-once/query-many at matched compute,
    against frame-rollout WMs (GPC-RANK, DINO-WM) and a direct D_direct(C, A, q).
  - A label-free reader remains an ablation, not a requirement.

## 6. Novelty and required opponents

| [RaMP, NeurIPS 2023](https://papers.neurips.cc/paper_files/paper/2023/file/b048dd19ba6d85b9066aa93b4de9ad4a-Paper-Conference.pdf) | Action-sequence-conditioned cumulative feature prediction | Ordered/nonadditive path queries and matched successor/multi-bin controls |
| [Value-equivalent rate-distortion, NeurIPS 2022](https://proceedings.neurips.cc/paper_files/paper/2022/hash/3b18d368150474ac6fc9bb665d3eb3da-Abstract-Conference.html) | Decision-related lossy model compression | A specific self-supervised algorithm and controlled evidence; no claim to invent rate-distortion |
| [VJEPA](https://arxiv.org/abs/2601.14354) | Variational/probabilistic JEPA | Distributional prediction alone is not our novelty; citation treated as a preprint here |
| [TD-Flow, ICML 2025](https://proceedings.mlr.press/v267/farebrother25a.html) | Generative long-horizon state prediction | Retain conditional path information beyond single discounted-state samples |

This is a plausible adaptation of established principles, with material novelty risk.
A renamed encoder plus a positive number is insufficient. The decisive ablations are
context at the reader, segment versus per-frame coding, and predictability-aware
versus query-only target learning. If a conditional per-frame codec matches the
frontier, the claimed segment contribution fails.

GCQ's [method description](https://arxiv.org/html/2510.16039v1) uses attractor-derived,
action-conditioned codeword sequences, template matching, commitment and observation
reconstruction losses. We do not claim to introduce joint space/time quantization.
The proposed question concerns which conditional path information to preserve for
held-out visual queries and whether co-design with its action prior improves the
prediction/compression frontier. This distinction requires evidence, not terminology.

## 7. What a positive result would look like

At least one predeclared rate/latency point improves the frontier against BOTH a
conditional compact-frame control and cached direct-query predictor. Accept either
lower query distortion at matched compute or lower end-to-end latency with a fixed
noninferiority margin. Fix the chosen primary path before confirmatory data are read;
do not switch the headline after looking at test results.

For the initial efficiency hypothesis, target >=2x predictor-plus-reader speed at
fixed K and Q, with <=2 percentage-point physical-success loss versus the strong
frame reference; additionally demand a measured end-to-end benefit after policy,
encoding and shared history costs. Pure predictor speed is not sufficient if proposal
generation dominates. Report the complete frontier, not only the winning token count.

The control hypothesis separately requires an absolute success improvement versus
the frozen policy, or a comparable success level at lower TOTAL planning latency
than the frame-WM planner. Fresh root episodes and at least three training seeds are
required for confirmation. No current result meets these conditions.
