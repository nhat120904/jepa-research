\section{World-Model Prediction Targets}
\label{sec:problem}
Let $C_t$ contain recent visual observations and proprioception. A candidate action chunk $\bA_t=(a_t,\ldots,a_{t+L-1})$ induces a future segment $\tau_t$, comprising sampled future image features and endpoint proprioception. The world model forecasts a representation of $\tau_t$ before any of those observations is available. A goal query $g$ specifies how the prediction is evaluated.

CTA learns the target jointly from context and future:
\begin{equation}
S=q_\phi(C,\tau),\qquad
p_\theta(S\mid C,\bA),\qquad
s=D_\psi(C,\hat S,g),
\label{eq:contract}
\end{equation}
where $\hat S=\E_{p_\theta}[S]$ in the implemented planner. The source encoder $q_\phi$ operates only during training. At deployment, the reader receives context, forecast, and goal, with no candidate actions. Therefore the world model is the only candidate-specific input path to the reader.

The target consists of $M=16$ finite-scalar-quantization tokens with levels $(8,8,4)$~\cite{mentzer2024fsq}. Each token has 256 grid values. The source alphabet bounds target capacity, while conditioning allows the encoder and readout to share context. Our training objective shapes what the code retains through ranking and feature reconstruction; it does not explicitly minimize conditional entropy. Deployment uses a continuous $16\times3$ coordinate mean. Source token capacity and deployed numerical precision are distinct quantities.

For control, a frozen policy supplies $K$ proposals. The reader scores each predicted segment, and the planner executes the highest-scoring chunk, using the smallest index to break ties, before replanning. A label $\ell(C,\tau,g)$ supplies supervision on training branches; it is not a deployment input. Offline evaluation uses identical banks, whereas closed-loop states and subsequent banks depend on earlier choices.
