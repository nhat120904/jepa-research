# Physics and robustness scan — 2026-09-30

Research only. No models loaded, videos decoded, experiments run, or jobs submitted. Sources below distinguish accepted proceedings from collision checks that remain preprints. Recommended sixth area: **robustness of frozen video classifiers under released video corruptions**, because a task head, labels, and a bounded archive exist. Physical counterfactual QA has stronger conceptual appeal but no verified complete no-training adapter from the cached action-free V-JEPA2 model to intervention answers.

## What the cached model can establish

V-JEPA2's action-free predictor performs masked latent prediction. A surprise score compares a prediction from observed context with features of an observed continuation. This supports plausibility discrimination. It does not supply a learned `do(remove object)` operation, an interpretable scene simulator, or a text-to-intervention interface. V-JEPA2-AC is a separate robot-data-posttrained action-conditioned model; its manipulation action space cannot be assumed to implement CLEVRER object removal. This distinction follows the [official model release](https://github.com/facebookresearch/vjepa2).

Therefore, an IntPhys2 result should be described as **physical plausibility discrimination**, not counterfactual simulation or VLM reasoning improvement. A proposed VLM benefit must ultimately be measured in question-answer accuracy; a lower latent prediction error is insufficient evidence.

## Probe 1: fixed no-training physical plausibility baseline — ready with cached model

**Assets.** [HF IntPhys2](https://huggingface.co/datasets/facebook/IntPhys2/tree/main) is approximately 1.82 GB overall and consists of individual MP4 files plus split metadata. Main has 253 scene quadruplets (1,012 videos), Debug has 60 videos, and HeldOut has 344 videos without labels. An initial 256-video pilot should select **64 complete Main scenes**, yielding 128 matched comparisons. Choose scenes deterministically and stratify physics condition, camera, and difficulty before reading outcomes; preserve the manifest.

**Metric.** Let `s(v)` be one fixed video surprise aggregation. Compare `1_Impossible` against `1_Possible`, and independently `2_Impossible` against `2_Possible`, within `SceneIndex`. Primary score is the fraction with `s(impossible) > s(possible)`; publish the tie rule. Bootstrap scenes, not individual videos or the two correlated pairs. Temporal-max surprise can be fixed as primary, temporal-mean as secondary, with context fixed in advance. Do not choose the best context/aggregation on Main labels. Report paired accuracy overall and by camera/condition/difficulty; the latter are established diagnostics, not novelty. Single-video threshold accuracy is a different task.

**Exact released paths and implementation constraints.**

- Config: [`prediction_evals/evals/intphys2/configs/vjepa_2.yaml`](https://raw.githubusercontent.com/facebookresearch/IntPhys2/main/prediction_evals/evals/intphys2/configs/vjepa_2.yaml). It defaults to ViT-H at 256, `intphys2-debug`, 48 frames, sampling every 10 source frames, stride 2, contexts `[12,18,24,30,36,42]`, BF16, and `max_context_mode:true`. Change the model architecture/config to the cached **ViT-g256** checkpoint and dataset to Main; do not reuse Huge kwargs silently. A smaller single-context protocol is acceptable if disclosed.
- Wrapper: [`app.vjepa.modelcustom.default_wrapper.AnticipativeWrapperNoAR`](https://raw.githubusercontent.com/facebookresearch/IntPhys2/main/prediction_evals/app/vjepa/modelcustom/default_wrapper.py). Targets are layer-normalized future target-encoder features; surprise extraction uses L1 averaged over target tokens and channels in [`eval.py`](https://raw.githubusercontent.com/facebookresearch/IntPhys2/main/prediction_evals/evals/intphys2/eval.py).
- Actual HF [`Main/metadata.csv`](https://huggingface.co/datasets/facebook/IntPhys2/resolve/main/Main/metadata.csv) header is `SceneIndex,name,file_name,game_name,condition,env,type,occluder,Difficulty,Camera`. Released [`intphys2_dataset.py`](https://raw.githubusercontent.com/facebookresearch/IntPhys2/main/prediction_evals/evals/intphys2/intphys2_dataset.py) expects `filename`: adapt this field explicitly. File paths are relative to Main, e.g. `Videos/<hash>.mp4`. Pair by keys, not CSV row or hash order.
- The default predictor config contains `num_heads` and `use_rope`, while its wrapper also passes them explicitly: duplicate kwargs cause a construction error. The wrapper suppresses missing-checkpoint errors and replaces shape-mismatched parameters with initialization. Require strict original checkpoint loading and explicit key/shape audit; otherwise the result may use random weights.
- Require `use_mask_tokens:true`. In the released predictor's alternate branch, target features can be passed through diffusion. Mask-token prediction must ignore future target values. A target-permutation test should leave predictions unchanged while altering losses; this is a correctness test, not a scientific probe.
- `max_context_mode` adds predictions with shorter contexts at the beginning of the video. It is **not** temporal max pooling. The code saves raw losses but supplies no complete predictive-score script. The [earlier JEPA evaluation](https://raw.githubusercontent.com/facebookresearch/jepa-intuitive-physics/main/evaluation_code/evals/intuitive_physics/eval.py) reports both temporal mean and max relative accuracy. State the chosen fixed protocol rather than claiming exact reproduction of the optimized paper table.

The IntPhys2 paper reports 57.51% Main and 56.40% HeldOut for V-JEPA2-H, with best hyperparameters selected from multiple runs. A fixed Giant pilot on 64 scenes is not directly matched to that optimized full-H result. Do not interpret a difference as an improvement without full matched evaluation.

## Probe 2: frozen task accuracy under bounded SSv2 corruption — assets verified, encoder match needed

**Question.** Does frozen latent predictability select a more reliable classification view under video compression, or does it favor static/uninformative content?

**Bounded assets.** The official [ViTTA SSv2 corruption directory](https://huggingface.co/datasets/wlin21at/ViTTA/tree/main/SSv2_val_corruptions) contains `h265_abr.zip` at **127,496,144 bytes**. Do not download the complete 199 GB corruption collection. Other individual archives are much larger: contrast 1.07 GB, defocus 1.63 GB, zoom 2.34 GB, motion 4.50 GB. Validate the selected archive's manifest and labels before model compute; use a deterministic bounded sample for the pilot. If clean videos are unavailable, report corrupted top-1 only, without claiming an accuracy drop from clean.

**Model compatibility.** The [official V-JEPA2 release](https://github.com/facebookresearch/vjepa2) lists an SSv2 attentive head for **Large256**, and one for **Giant384**, but none for cached Giant256. Public HTTP HEAD checks confirm Large's full [`vitl.pt`](https://dl.fbaipublicfiles.com/vjepa2/vitl.pt) is **5,127,726,842 bytes** and matching [`ssv2-vitl-16x2x3.pt`](https://dl.fbaipublicfiles.com/vjepa2/evals/ssv2-vitl-16x2x3.pt) is **198,078,572 bytes**. Both are accessible. Use an already cached matching Large pair or a bounded ~5.33 GB model download; otherwise mark this probe blocked. Do not attach Giant384's head to Giant256 and silently treat it as the released classifier.

The [`configs/inference/vitl/ssv2.yaml`](https://raw.githubusercontent.com/facebookresearch/vjepa2/main/configs/inference/vitl/ssv2.yaml) protocol uses target encoder, 16 frames sampled every 4 frames, 2 temporal segments × 3 spatial views, resolution 256, and 174 classes. The Giant384 head uses 64 frames every 2 frames and the matching 384 encoder. A predictor-mask protocol must additionally be fixed for residual scoring; its mismatch with classifier clips must be disclosed.

**Comparison.** Use the same candidate views for (a) official uniform logit/probability aggregation, (b) confidence or entropy selection/weighting, and (c) one predeclared WM residual selector or fixed weighting rule. No gradient update, new head fitting, label-based temperature tuning, or test-set layer selection. Compare **top-1 classification accuracy**, per-video paired accuracy differences with bootstrap uncertainty, predictor calls, encoder calls, and latency. A residual-vs-error association can be secondary. If WM selection improves residual yet decreases top-1, the proposed mechanism fails this task.

ViTTA/TeCo are trained test-time adaptation baselines and useful final-paper competitors, but a quick frozen comparison should first establish benefit over uniform aggregation and confidence at matched view count. The scan did not verify an accepted exact frozen-WM view-selector evaluation on this corruption release; that absence is not proof of novelty.

## Optional third probe and blockers

For physical anomaly detection, frozen surprise versus released zero-shot Video-LLaVA/LAVAD/CLIP/ImageBind scores on Phys-AD would measure **video AUROC**, not latent MSE or an ungrounded causal label. Its [official archives](https://huggingface.co/datasets/guoliz/Phys-AD/tree/main) total 32.1 GB in seven parts, mostly around 5.3 GB; the 196 MB final part is not verified as a self-contained subset. Do not download that fragment and assume it is a valid task sample. This is a later probe after bounded subset access is established. A causal-anomaly claim would additionally require labeled interventions/causes and an appropriate causal task metric, which ordinary anomaly AUROC does not provide.

CLEVRER remains blocked for a strict no-training latent-WM-assisted QA comparison until a released intervention-capable model and complete answer reader are verified. Causal-JEPA's trained QA pipeline and PhysMind's presently unverified complete release are substantive blockers. Physion similarly requires a matched contact readout. GeoPhys cannot be labeled a reproduced baseline while its official code is unreleased. Neither plaintext latent coordinates nor an arbitrary frozen VLM prompt supply the missing learned semantic interface.

**Priority:** run the IntPhys2 fixed baseline/control first with the cached original Giant model; run the bounded SSv2 task probe only with a matching released head/encoder. Treat these as evidence about signal utility, not a CVPR novelty claim. The accepted papers and newer collisions make a generic “latent world model helps physics/counterfactual/anomaly reasoning” contribution insufficiently specific.
