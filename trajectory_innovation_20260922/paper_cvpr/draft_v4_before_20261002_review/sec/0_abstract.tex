\begin{abstract}
A world model predicts how the environment will respond to an agent's actions, and a planner uses these predictions to choose among candidate actions.
Latent world models such as DINO-WM predict the visual features of every future frame, and plan by comparing the last predicted frame with a goal image in feature space.
When a robot must choose among a few candidate action chunks, much of this prediction restates what the history already shows, and feature distance to a goal image can be a poor measure of task progress.
We ask whether a world model can instead predict a compact abstraction of an action's entire future that keeps what the decision needs and omits what the history already reveals.
We propose \emph{Conditional Trajectory Abstraction} (\method), a joint-embedding world model whose prediction target is learned.
During training, a target encoder compresses the actual future of an action chunk into 16 discrete tokens, conditioned on the observed history.
A goal-conditioned reader ranks sibling futures by task progress from the history and this code alone, and a feature decoder reconstructs the future's frozen image features, so that the code describes the future instead of merely scoring the training goals.
The world model predicts the code from the history and a candidate chunk in a single forward pass.
Because the code does not depend on the goal, each candidate is predicted once and can then be evaluated by the reader for any goal.

An attribution ladder separates the ranking quality lost by compressing the future from that lost by predicting it.
\end{abstract}
