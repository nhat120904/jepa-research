\section{CTA World Model}
\label{sec:method}
CTA separates learning a useful prediction target from forecasting it. First, a conditional target encoder, reader, and feature decoder learn from observed action consequences. Second, a world model learns to forecast the frozen target from context and actions. At deployment, only the world model and reader are used (\cref{fig:architecture}).

\subsection{Learning the conditional future target}
\label{sec:source}
\paragraph{Context and future features.}
We encode images with frozen DINOv2 ViT-S/14~\cite{oquab2024dinov2} and project features to 128 dimensions using PCA fitted on training images. Native $96\times96$ observations are resized to $224\times224$. Context $C$ contains 256 current-image tokens, 64 pooled previous-image tokens, and one proprioception token embedding current and previous agent positions. The source future $\tau$ contains an endpoint feature grid, three pooled intermediate grids, and endpoint proprioception. For $L=8$, intermediate samples are steps $(2,4,6)$; for $L=15$, they are $(4,8,11)$. Samples beyond termination repeat the final observation.

\paragraph{Conditional encoding.}
Sixteen learned queries cross-attend to the context and future tokens through a three-layer Transformer decoder. A projection produces three coordinates per query; finite scalar quantization (FSQ)~\cite{mentzer2024fsq} maps them to levels $(8,8,4)$ with straight-through gradients. For level $l$, the grid is $\mathcal Q_l=\{(r-\lfloor l/2\rfloor)/\lfloor l/2\rfloor\}_{r=0}^{l-1}$. The resulting segment code has $16\times3$ coordinates, independent of the number of sampled future feature tokens. It represents the future jointly with the observed context rather than reconstructing a standalone trajectory.

\paragraph{Decision and feature supervision.}
A goal-conditioned Transformer reader produces $D_\psi(C,S,g)$. Training banks contain $K$ sibling futures executed from the same initial state. Let $\ell_{bi}$ denote the training utility of candidate $i$ in bank $b$, and let $\mathcal P=\{(b,i,j):\ell_{bi}-\ell_{bj}>\epsilon\}$. We train the reader and encoder using
\begin{equation}
\mathcal L_{\rm rank}(s,\ell)=\frac{1}{|\mathcal P|}
\sum_{(b,i,j)\in\mathcal P}\operatorname{softplus}[-(s_{bi}-s_{bj})].
\label{eq:rank}
\end{equation}
An empty pair set contributes zero. Within-bank supervision reflects the planner's selection operation without requiring globally comparable scores.

A separate decoder $G_\xi(C,S)$ reconstructs endpoint and intermediate \emph{image} features as residuals from current features. The endpoint and intermediate MSE terms are normalized by their train-set copy-current errors and averaged as $\mathcal L_{\rm feat}$. This provides visual supervision beyond the scalar ranking label. The source-stage objective is
\begin{equation}
\mathcal L_{\rm source}=\mathcal L_{\rm rank}
+\alpha\mathcal L_{\rm feat}
+\lambda_{\rm sat}\E[(|z_{\rm pre}|-1.5)_+^2].
\label{eq:source}
\end{equation}
The final term regularizes pre-quantization saturation. Both the reader and feature decoder share context with the encoder; neither receives candidate actions.

\subsection{Forecasting the segment with a world model}
\label{sec:wm}
The predictor encodes $C$ and the candidate action sequence. Each action $a_h$ is embedded as $[a_h/512-1/2,(a_h-p_t)/64]$, combining absolute and relative positions. Sixteen queries decode a segment forecast in parallel through four decoder layers, following a four-layer context/action encoder. There is no autoregressive rollout of intermediate feature grids.

The output is a categorical distribution for each token coordinate:
\begin{align}
p_\theta(S\mid C,\bA)&=\prod_{m=1}^{M}\prod_{j=1}^{3}p_{\theta,mj}(S_{mj}\mid C,\bA),\\
\hat S_{mj}&=\sum_{r=0}^{l_j-1}p_{\theta,mj}(r\mid C,\bA)\mathcal Q_{l_j}[r],
\label{eq:mean}
\end{align}
where $(l_1,l_2,l_3)=(8,8,4)$. The shared Transformer models interactions in its hidden computation, while the categorical output distribution factorizes over coordinates. We train with the mean coordinate cross-entropy $\mathcal L_{\rm NLL}$ against the realized source code. The reader evaluates the continuous coordinate mean $\hat S$; this is a deterministic readout of the forecast distribution, not an expectation of the nonlinear reader's score.

\subsection{Aligning forecasts with the decision readout}
\label{sec:reader}
During world-model training, the source encoder and reader are frozen. Let $u_k=D_\psi(C,S^{(k)},g)$ be the teacher scores and $s_k=D_\psi(C,\hat S^{(k)},g)$ the predicted scores. We align their relative values within a bank:
\begin{equation}
\mathcal L_{\rm cons}=\operatorname{SmoothL1}\!\left(
\frac{s-\bar s}{T},\frac{\sg(u)-\bar u}{T}\right).
\label{eq:cons}
\end{equation}
Here $T$ is a train-only RMS teacher-score scale, floored at $10^{-3}$. Centering removes a bank-wide offset, which does not affect action selection. Weighted ranking additionally multiplies each term in \cref{eq:rank} by $w_{ij}=\min(1,(\ell_i-\ell_j)/\sigma)$, with the same pair-count denominator. The complete world-model objective is
\begin{equation}
\mathcal L_{\rm WM}=\mathcal L_{\rm NLL}+\mathcal L_{\rm cons}+\mathcal L_{\rm rank}^{w}.
\label{eq:pred}
\end{equation}
Gradients through the frozen reader guide the forecast toward distinctions used by the planner; the reader's parameters remain unchanged.

For a fixed bank, a maximum centered score error $\varepsilon$ implies source-reader regret at most $2\varepsilon$. A unique source-score margin larger than $2\varepsilon$ therefore preserves the selected action. The supplement proves this elementary stability bound. It motivates readout consistency but does not establish native task regret without additional calibration assumptions.

\subsection{Training recipe and planning}
\label{sec:training}
Training executes standard and perturbed policy proposals from cloned simulator states. All sibling branches from an episode remain in one split. The dense training utility is the negative mean distance between eight corresponding block and target vertices, divided by 512. These privileged labels supervise training; deployment uses images, agent positions, actions, and image goals. Native evaluation uses PushT coverage success rather than a threshold on the training label.

We use AdamW with learning rate $3\times10^{-4}$, weight decay .05, dropout .1, and 16 banks per update. Source and prediction stages run for 16,000 and 10,000 updates, respectively, with development checkpoint selection. We set $\alpha=\lambda_{\rm sat}=1$, $\epsilon=.001$, and $\sigma=.01$. All Transformer modules use width 256 and eight heads; the reader has four layers and the reconstruction decoder two. The supplement specifies data mixtures, selection views, selected checkpoints, and optimizer grouping.

\begin{algorithm}[t]
\caption{CTA world-model planning at one decision}
\label{alg:cta}
\small
\begin{algorithmic}[1]
\Require observed context $C$, goal features $\cG$, policy $\pi$
\State $\{\bA^{(k)}\}_{k=1}^{K}\gets\pi(C)$
\State $\hat S^{(k)}\gets\E_{p_\theta(S\mid C,\bA^{(k)})}[S]$ for all $k$
\State $s_k\gets|\cG|^{-1}\sum_{g\in\cG}D_\psi(C,\hat S^{(k)},g)$
\State choose the smallest index $k^\star$ maximizing $s_k$
\State execute up to $L$ actions; observe and replan
\end{algorithmic}
\end{algorithm}
The prediction is independent of $g$, so context features and segment forecasts can be cached across reader queries. A new raw goal image requires its own feature extraction. This separation is an architectural property; the experiments measure its component cost under repeated queries.
