\section{Related Work}
\label{sec:related}
\paragraph{Visual and latent world models.}
Latent dynamics models such as PlaNet learn compact state transitions from images for planning~\cite{hafner2019planet}. Joint-embedding predictive architectures predict representation-space targets instead of generating pixels~\cite{assran2023ijepa}. DINO-WM learns action-conditioned prediction on frozen DINOv2 features~\cite{zhou2025dinowm}; V-JEPA~2-AC post-trains an action-conditioned predictor on a frozen video representation~\cite{assran2025vjepa2}. Their spatial targets support rich visual prediction, but do not directly answer how a single segment-level target should be learned. CTA retains a pretrained visual input representation while learning an additional conditional target for an action segment.

\paragraph{Compact and conditional prediction targets.}
CompACT learns compact discrete image representations for latent world-model rollouts~\cite{kim2026compact}. Delta-IRIS introduces context-aware temporal tokenization~\cite{micheli2024deltairis}, and contextual video compression uses shared side information when coding observations~\cite{li2021dcvc}. TAP encodes state-conditioned trajectories in a discrete latent action space and searches over those codes~\cite{jiang2023tap}. CTA instead forecasts a future code induced by an externally supplied action chunk, then evaluates it with a learned reader. Compactness, conditioning, and trajectory coding have clear precedents; the distinction is the source target and forecast/readout interface. A matched compact per-frame control would further isolate the temporal choice.

\paragraph{World models for policy steering.}
Generative Predictive Control ranks or refines policy proposals using predicted consequences~\cite{qi2025gpc}. FOREWARN aligns latent prediction with visual-language reasoning~\cite{wu2025forewarn}; DreamSteer uses predicted visual progress to steer deployed policies~\cite{cui2026dreamsteer}. Robot Critics learns progress comparisons from success/failure rollouts and applies them to generated consequences~\cite{sudhakar2026critics}. DynaGuide guides diffusion denoising with learned dynamics~\cite{du2025dynaguide}. CTA uses proposal selection to study its world-model target; proposal selection and action-blind outcome evaluation are established planning interfaces. Our endpoint comparator is a matched learned model, not a reproduction of GPC.

\paragraph{Decision-oriented representations and direct guidance.}
Value equivalence and value-equivalent sampling formalize preserving model information needed for value-based decisions~\cite{grimm2020value,arumugam2022deciding}; TD-MPC2 learns control-oriented latent dynamics~\cite{hansen2024tdmpc2}. V-GPS and RoboMonkey evaluate proposed actions directly~\cite{nakamoto2024vgps,kwok2025robomonkey}. These approaches motivate decision-aware representation learning and provide useful alternatives to explicit prediction. CTA supervises the prediction target using a ranking reader and future features. We compare with direct scoring without assuming that an explicit world model is necessary for good control.
