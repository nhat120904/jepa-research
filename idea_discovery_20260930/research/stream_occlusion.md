# Streaming perception and occlusion: evidence scan

Research-only scan, 2026-09-30. No models loaded, inference run, jobs submitted, or results claimed. Published numbers below are literature results, not our reproductions. Conference framing uses accepted main-track CVPR/ICCV/ECCV/ICLR/NeurIPS work. Explicitly marked preprints are novelty blockers or implementation evidence.

## Decision

**Generic frame skipping, feature rollout, adaptive routing, and object-permanence tracking are already established.** A narrow candidate remains worth a bounded no-training probe: replace an unobserved next-frame feature map with a frozen predictor output, keep the exact same nonparametric correspondence head, and test final DAVIS masks against repeat/copy/past-motion controls at identical observation budgets. This tests an actual mechanism; it does not establish a CVPR contribution or justify selecting the direction before results.

**Do not propose frozen V-JEPA 2 as an immediately usable causal dense world model.** Its predictor is a masked-feature predictor; its encoder is bidirectional, its feature space is weaker for local structure, and its native task heads are trained. A training-free mask propagator is available as an adapter, but prediction quality and correspondence compatibility remain empirical questions. Amodal completion is a separate, harder task: predicting the representation of the actually visible video does not by itself supervise hidden-object masks.

## Preprints / released models that further narrow novelty

These are not used as accepted conference framing.

- [V-JEPA 2.1, March 2026 preprint](https://arxiv.org/html/2603.14482v3): its encoder already supports nonparametric mask propagation; reported DAVIS17/YouTube-VOS J&F are 69.0/72.7. Original V-JEPA2 ViT-g scores 52.5 DAVIS J&F in its comparison table. The selected propagator uses first frame plus 15 recent frames, circle radius 12 patches, top-5 neighbors, temperature 0.2, short side 480. YouTube-VOS here uses a custom 80/20 split of the public training set, **not** the official challenge validation protocol. Published dense correspondence is therefore not a gap. The paper does not specify a sufficiently precise video extraction/cutoff procedure to infer strict causality. The official repository tree inspected at `204698b45b3712590f06245fbfba32d3be539812` contains no VOS/DAVIS evaluation implementation.
- [Lean-SAM2, July 2026 preprint](https://arxiv.org/abs/2607.19811): prompt-anchored token selection, visibility-gated memory condensation, insurance memory, and risk-aware full-frame refresh. Close blocker for adaptive savings plus occlusion safety.
- [SENTRY, June 2026 preprint](https://arxiv.org/abs/2606.24449): training-free hypothesis validation through short tracklets and cycle-consistent temporal/geometric matching before memory writes. Blocks generic “temporal consistency verifies memory updates.”
- [SAM2Dual, August 2026 preprint](https://arxiv.org/abs/2608.18640): training-free short/long-term memory, gated fusion, and text-based memory compatibility. Blocks generic dual-memory proposals.
- [Zero-shot World Models Are Developmentally Efficient Learners, April 2026 preprint](https://arxiv.org/abs/2604.10333) / [release](https://github.com/awwkl/ZWM): prediction under input perturbations gives task-free correspondences/segmentation; code evaluates TAP-Vid-DAVIS point pairs by EPE. [Author lab lists it “in submission”](https://web.stanford.edu/group/neuroailab/publications.html). Broad “world model induces correspondence without task training” is already claimed.

## Frozen predictor audit: what a valid probe can and cannot do

Code URLs are pinned to the inspected official V-JEPA2 commit:

- [Original encoder](https://github.com/facebookresearch/vjepa2/blob/204698b45b3712590f06245fbfba32d3be539812/src/models/vision_transformer.py): `forward(x, masks)` patchifies then removes unwanted tokens before transformer blocks. Blocks receive `attn_mask=None`. **Encode-full-clip then slice past features leaks future evidence.** Align cutoff to complete two-frame tubelets; a retained tubelet must not contain an unseen frame. A safe padded tensor may hold arbitrary future placeholders only if every corresponding token is removed before attention.
- [Original predictor](https://github.com/facebookresearch/vjepa2/blob/204698b45b3712590f06245fbfba32d3be539812/src/models/predictor.py): API `forward(x, masks_x, masks_y, mask_index=1)`. Context and target indices refer to flattened spatiotemporal patch positions. Target mask tokens are concatenated with context, sorted, processed without a causal attention mask, restored to original input order, and projected. Output corresponds to `masks_y` order. Past-only context can make inference causal despite bidirectional processing of context/mask tokens; the pretrained objective does not guarantee accurate future extrapolation or long rollout.
- [Hub construction/checkpoint compatibility](https://github.com/facebookresearch/vjepa2/blob/204698b45b3712590f06245fbfba32d3be539812/src/hub/backbones.py): original ViT-g encoder and predictor output both use 1408 channels, permitting cosine label propagation without fitting a head. Loader expects `target_encoder` and `predictor` states. Its current base URL is a localhost testing endpoint; instantiate from the pinned config and load an explicitly downloaded checkpoint, or repair only the loader URL. Use [official model links](https://github.com/facebookresearch/vjepa2#models), including `https://dl.fbaipublicfiles.com/vjepa2/vitg.pt`.
- [V-JEPA2.1 predictor](https://github.com/facebookresearch/vjepa2/blob/204698b45b3712590f06245fbfba32d3be539812/app/vjepa_2_1/models/predictor.py) / [encoder](https://github.com/facebookresearch/vjepa2/blob/204698b45b3712590f06245fbfba32d3be539812/app/vjepa_2_1/models/vision_transformer.py): hierarchical predictor inputs/outputs differ from final-layer encoder features. Distilled B/L predictor outputs are teacher-space 1664-D, while B/L encoder features are 768/1024-D. They are not a drop-in recursive transition or directly comparable cosine feature maps. Giant/Gigantic require the proper concatenated hierarchical features and compatible output layer selection.

**Task head:** nearest-neighbor mask propagation uses only the first-frame annotation and model-generated past probabilities, so it needs no task-head training. A SAM2 mask decoder does not consume V-JEPA vectors directly; inserting such vectors requires an aligned adapter or different nonparametric reader. Original V-JEPA2's released recognition/anticipation probes are already task-trained, so “frozen backbone” is not equivalent to “no task training.” [Official usage](https://github.com/facebookresearch/vjepa2#probe-based-evaluation).

**Occlusion interpretation (inference):** masked-feature supervision targets the representation of observed pixels. If an object is hidden, those pixels belong to its occluder. A frozen predictor can retain useful identity/dynamics, but predicting this target does not establish an amodal mask representation. DAVIS visible masks score disappearance/reappearance; they do not measure complete hidden-object shape.

## Concrete no-training probe for root to implement

**Primary comparison: frozen V-JEPA2 ViT-g/256 future map vs repeat at identical encoded anchors.**

1. Predeclare sequences and keep full sequence ordering/annotations. Input uses identical resize/normalization and a fixed observed context length. At an anchor, encode only observed complete tubelets; keep identical anchor schedule in every arm. Never refresh based on ground-truth errors.
2. At skipped target frames, arm P predicts target-token vectors from retained past context and target position masks. Arm R supplies the last observed feature map to the same reader. Add copy-last-mask separately: repeated vectors plus recursive kNN is not identical to mask copying. A useful third arm extrapolates flow estimated solely between already observed frames; target-frame optical flow uses extra observations and must be labelled separately.
3. Reader reference: [official DINOv3 tracking notebook pinned at `6876159a11b4df116f30f667f8c9888617df0751`](https://github.com/facebookresearch/dinov3/blob/6876159a11b4df116f30f667f8c9888617df0751/notebooks/segmentation_tracking.ipynb). Normalize patch vectors; restrict source candidates to a circle; take top-5 across first-frame plus recent context patches; softmax cosine scores at temperature 0.2; multiply context probabilities; upsample and argmax. Set one fixed context/radius protocol across arms. Its demonstration defaults to seven recent frames; paper reproduction uses fifteen. [Older official DINO script](https://github.com/facebookresearch/dino/blob/main/eval_video_segmentation.py) instead uses square neighborhoods / 0.1 temperature, so do not mix its defaults with the claimed 2.1 protocol.
4. Only frame-zero GT initializes the reader. Subsequent GT is read exclusively by the evaluator. Original ViT-g predicted and observed maps share 1408 channels, but contextual teacher/student distribution mismatch is still possible. Log prediction mask-token index and target ordering. Prediction autoregression is not necessary for the first probe; predict skipped positions directly from the last observed context.
5. Score actual indexed-mask PNGs with the official DAVIS evaluator. Report per-sequence J, F, J&F and paired differences, plus uncertainty across sequences. Track encoder observations, processed encoder tokens, predictor invocations/tokens, reader work, elapsed GPU runtime, and peak memory. Equal observations do not imply equal total compute: P pays predictor overhead. A full-current-frame encoding arm is an informative upper/reference arm, not an observation-matched baseline.

Use the same final J&F on a predeclared occlusion/reappearance subset to investigate mechanism. Report complete-sequence metrics first; any hand-selected failure examples are diagnostic. A positive result on four videos remains a pilot, not proof against SAM2 or the published 30-video benchmark.

**Selection meaning:** prediction must improve the final correspondence task over strong cheap controls while reducing or fairly accounting for total inference cost. A low latent error alone is insufficient. Failure would specifically reject this frozen feature-replacement setup, not every latent world-model application. Success would justify investigating uncertainty-driven refresh and disocclusion, with the accepted propagation/routing methods above as mandatory baselines.
