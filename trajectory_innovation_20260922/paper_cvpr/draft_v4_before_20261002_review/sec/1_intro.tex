\section{Introduction}
\label{sec:intro}

A world model predicts how the environment evolves in response to an agent's actions~\cite{hafner2019planet,hafner2023dreamerv3}.
Prediction alone does not choose an action: a planner evaluates the predicted outcomes of candidate actions against a goal, for example with a cost or a learned reward.
In visual control, a prominent line of work learns the world model in the feature space of a frozen pretrained encoder.
DINO-WM~\cite{zhou2025dinowm} and V-JEPA~2-AC~\cite{assran2025vjepa2} predict the patch features of every future frame, and plan by minimizing the distance between the features of the last predicted frame and those of a goal image.
Predicting features avoids generating pixels, and because the goal enters only through the cost, one world model serves any goal image.

When a robot must choose among candidate action chunks, however, a per-step latent target spends computation where the decision does not need it and leaves open what the decision does need.
Each candidate requires predicting a full grid of feature tokens for every future step, 2{,}048 tokens for an 8-step chunk in our PushT setup, even though the scene layout, the appearance of objects, and everything the action does not touch are already visible in the history.
The predicted frames must then be turned into a decision, and a generic feature distance to a goal image is a weak measure of task progress.

On PushT, ranking the proposals of a diffusion policy by the DINOv2 distance between their \emph{true} future frames and goal images raises success by only \result{3} points, whereas a reader trained to rank true futures by task progress raises it by \result{8.5} points (\cref{tab:main}).
A per-step world model that plans with feature distance inherits the first ceiling even if its predictions are perfect.

The opposite extreme predicts nothing.
A direct scorer maps the history, a candidate action, and the goal to a score~\cite{nakamoto2024vgps,kwok2025robomonkey}.
It is cheap and trained for the decision, but its internal representation is shaped only by the training labels.
Nothing asks it to model what the action does to the scene, so whatever it learns about dynamics is entangled with the goals and labels it was trained on.

We argue that a world model for decision making should predict something in between: a compact description of what the action will do that contains only what the decision needs and only what the history does not already reveal.
The second requirement is the principle of conditional video coding~\cite{li2021dcvc}: when the encoder and the decoder share the past frames, bits need to be spent only on what the past frames do not predict.
We apply this principle to the future of an action that has not yet been executed, and we learn the first requirement from task-progress labels instead of fixing it in advance.

We call the resulting model \emph{Conditional Trajectory Abstraction} (\method, \cref{fig:overview}).
During training, a target encoder compresses the actual future of an action chunk, including its intermediate frames, into $M{=}16$ discrete tokens, conditioned on the history.
Two heads read this code together with the history but never see the action.
A reader ranks sibling candidates by progress toward a goal image, and a feature decoder reconstructs the future's frozen image features.
Because neither head sees the action, everything the action changes must pass through the code, and the decoder prevents the code from degenerating into a score for the training goals.
The world model is the predictor of a joint-embedding predictive architecture~\cite{lecun2022path,assran2023ijepa}: it predicts the stop-gradient code from the history and a candidate chunk in one forward pass and never generates an image.
At deployment, a frozen policy proposes candidate chunks, the world model predicts one code per candidate in a single batched pass, and the reader ranks the candidates.
Since the code does not depend on the goal, a new goal costs only reader evaluations: \emph{predict once, query many}.

Each ingredient of \method has precedents in world models, video compression, and policy steering, so we state our claims as controlled comparisons.
All scorers rank the same proposals, see the same history, and are trained on the same data and labels; they differ in what they predict about the future: every frame, the final frame, nothing, or the conditional code.
Our contributions are:
\begin{itemize}[leftmargin=*,topsep=2pt,itemsep=1pt]
\item a formulation of a world model's prediction target as a rate-limited code of an action's future segment, conditioned on the history, which contains the per-step latent world model and the direct scorer as its two limiting cases;
\item \method, a joint-embedding world model whose target is learned with a goal-conditioned ranking reader and a conditional feature decoder, and which predicts the code of every candidate in one pass;
\item an attribution ladder that scores the same decisions from the true future, from its code, and from the predicted code, separating the ranking quality lost to compression from that lost to prediction;
