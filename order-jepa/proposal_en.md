# Research Proposal: ORDER-JEPA — Learning Action-Order Effects for Latent Planning

Literature review date: September 7, 2026. This is a research proposal, not a benchmarked method. The analytic check, physical qualification, and original-checkpoint predictor audit have now run; their results are recorded in [RUN_STATUS.md](RUN_STATUS.md). The audit returned `STOP_OR_FIX_STAGE_A`, and no JEPA has been trained in this study.

## Dataset and task qualification update

The original benchmark selection did not establish compatibility among the data distribution, observations and history, encoder, action interface, predictor, cost, horizon, and planner. The companion [compatibility and experiment-selection plan](compatibility_plan_en.md) supersedes the benchmark order and pilot schedule in the original draft. The first priority is an audit of DINO-WM with the official `pusht_noise` release and original PushT protocol. PushT and 3D navigation are not assumed to be suitable for ORDER in advance. The audit separates limits caused by search, representation and cost, and learned dynamics before any method training.

## Research decision

I propose studying whether latent dynamics preserve the effects of action order. The central question is: when two sequences contain the same actions in different orders, does a world model predict the correct *vector difference between their outcomes*? After controlling for prediction accuracy, action sensitivity, data, and compute, can this error explain and remedy planning failures?

The work should begin with an audit of a released checkpoint. A training pilot is justified only if that audit finds a remediable predictor gap. There is currently no basis for committing to a large training campaign or forecasting acceptance. If ordinary multi-step prediction on the same branch data resolves the entire problem, the new-method framing should be abandoned.

## Motivation and relation to recent work

Generic action sensitivity, inverse dynamics, candidate discrimination, and latent metric alignment are already crowded directions. Delta-JEPA decodes actions from latent displacement; ATM/AITS adds action-identification supervision; ActSWM encourages separation among action-conditioned rollouts; and CoCo introduces counterfactual constraints. A generic “action-aware loss” would therefore carry substantial overlap risk. See [Delta-JEPA](https://arxiv.org/html/2606.31232v1), [ATM/AITS](https://arxiv.org/html/2606.09028v1), [ActSWM](https://arxiv.org/html/2607.26712v1), and [CoCo](https://arxiv.org/html/2608.04653v1).

SCALE directly aligns latent geometry with task-relevant state, while Discriminative World Models for Web Agents uses branching outcomes to distinguish candidates. Neither planner-compatible geometry nor learning from alternative actions is independently novel. See [SCALE v2](https://arxiv.org/abs/2608.16287) and [Discriminative World Models](https://arxiv.org/abs/2609.02885).

The remaining hypothesis concerns the *interaction induced by action order* while holding fixed the initial state, action multiset, duration, and budget. This signal is more specific than arbitrary separation between futures.

Consider a robot facing right. Compare rotate-then-translate with translate-then-rotate. Both sequences use the same rotation and translation and end at the same heading, but at different positions. The difference describes how rotation changes the effect of translation. A model can distinguish rotation from translation while representing their composition incorrectly. Good action classification or inverse-dynamics accuracy does not certify correct action composition. Whether this failure actually occurs in well-trained DINO-WM or LeWM models remains an empirical question.

## Geometric-control principle

In a smooth system, primitive action (i) induces a vector field (f_i) and flow (Phi_i^h). Using the convention that (i) is executed before (j),

\[
s_{ij}=\Phi_j^h(\Phi_i^h(s)),\qquad
s_{ji}=\Phi_i^h(\Phi_j^h(s)).
\]

A Taylor expansion gives

\[
s_{ij}-s_{ji}=h^2[f_i,f_j](s)+O(h^3),
\qquad [f_i,f_j]=Df_j f_i-Df_i f_j.
\]

The first-order terms cancel. The remainder measures the noncommutativity of the two actions. Lie brackets are classical tools for analyzing directions generated by coordinated controls; see [Murray and Sastry](https://murray.cds.caltech.edu/Nonholonomic_Motion_Planning%3A_Steering_Using_Sinusoids) and LaValle on [Lie brackets](https://lavalle.pl/planning/node829.html) and [controllability](https://lavalle.pl/planning/node831.html).

A nonzero bracket does not guarantee planning success. Local controllability requires additional assumptions; global reachability also depends on obstacles, constraints, horizon, and search. Systems with drift require separate treatment; see [LaValle](https://lavalle.pl/planning/node836.html).

If a sufficiently observed smooth encoder defines a map (psi) from physical state to latent space, then

\[
\psi(s_{ij})-\psi(s_{ji})
=h^2D\psi(s)[f_i,f_j](s)+O(h^3).
\]

When (psi) is an appropriate embedding and latent fields are pushforwards of the physical fields, the bracket is preserved. A latent model with commuting fields cannot faithfully represent a physical bracket retained by (psi). This is a consequence of classical geometry, not a new theorem. It does not apply when observations are insufficient or the encoder discards the relevant direction.

## Proposed failure mode

Average prediction loss may underweight a second-order action-order signal. When (h) is small, the endpoint displacement caused by order is (O(h^2)), so completely missing it may contribute only (O(h^4)) squared error. A model can remain sensitive to each individual action while making this error.

This does not imply that JEPAs are incapable of learning order. Transformers and recurrent predictors can represent it, and sufficiently small uniform prediction error would preserve it. The hypothesis concerns error allocation under finite data and compute.

## Minimal intervention

The initial study uses frozen visual features as in DINO-WM and retains the predictor, action parameterization, observation history, and CEM planner. [DINO-WM](https://proceedings.mlr.press/v267/zhou25t.html) is an ICML 2025 baseline. Transfer to a trained and then frozen LeWM encoder may be tested later, but must be described as predictor fine-tuning with a frozen representation, not a reproduction of end-to-end [LeWorldModel](https://arxiv.org/abs/2603.19312).

The DINO-WM PushT code uses RGB and agent proprioception. Its visual encoder is frozen, while its proprio encoder is trained in the original recipe. In controlled fine-tuning, both observation encoders will be frozen from a shared checkpoint across all arms; ORDER will initially operate on visual endpoint differences, while proprioceptive error is reported separately. Because the full planning objective contains both visual and proprioceptive MSE, a visual-only order bound does not guarantee full-cost ranking.

At state (s), collect true rollouts (i\to j) and (j\to i). Each primitive lasts (r) simulator steps with duration (h). A fixed encoder provides targets

\[
z_{ij}=E(o_{ij}),\quad z_{ji}=E(o_{ji}),
\quad d=z_{ij}-z_{ji}.
\]

Starting from the same observation history, autoregressively unroll the predictor to obtain (hat z_{ij}) and (hat z_{ji}), and define (hat d=hat z_{ij}-hat z_{ji}). The proposed objective is

\[
\mathcal L_{\rm ORDER}
=\mathcal L_{\rm WM}
+\lambda\,\mathbb E\!\left[
\left\|\frac{\hat d-\operatorname{sg}(d)}{h^2}\right\|_2^2
\right].
\]

The pilot uses one fixed (h) large enough to yield a reliable signal. In that setting, (1/h^4) is merely absorbed into (lambda) and is not a novelty claim. (mathcal L_{\rm WM}) includes ordinary trajectories and both acquired branches, with matched supervised horizons in every baseline. Stop-gradient clarifies the training path; the frozen encoder prevents the targets from shrinking toward zero.

The loss matches both direction and magnitude. It does not force every action pair to differ: when the true (d=0), the target is zero. It assumes neither that negative actions are inverses nor that a zero action stops the environment. It requires two action orders from the same state, but no differentiable simulator, state labels for primary training, reward labels, or contact labels.

Inference retains the original latent rollout and goal cost. No new inference module is added, although real overhead must still be measured. Any macro-actions exposed to the method must also be exposed to every baseline.

## Data requirement

This is offline learning from a dataset containing branched interventions. It cannot be applied directly to arbitrary fixed offline trajectories. The simulator must restore all relevant state, velocities, controller state, and randomness. Identical images do not establish identical physical states.

Actions cannot be shuffled while retaining the old future frames. Nearby states cannot be labeled “same-state counterfactuals” without measuring their mismatch. Without branch outcomes, the current method lacks its required supervision.

Acquiring two branches costs (4NKr) transitions for (N) anchors, (K) action pairs per anchor, and (r) control steps per primitive. The earlier example (N=2{,}000), (K=2), (r=2) gave 32,000 transitions but did not match PushT. The revised pilot sets (r=5) to match one model step at frameskip 5, yielding 80,000 suffix transitions before warm-up, repeats, validation, and audit candidates. This is a proposed post-qualification budget, not evidence that the amount is sufficient.

Splits are made by episode and anchor before branching; all branches from an anchor remain in one split. Evaluation goals, test layouts, and test seeds cannot be used to choose (lambda) or (h). In stochastic settings, repeated branches estimate signal and noise. Common random numbers pair samples but do not create a stronger causal claim by themselves.

## A mathematical objection that must be acknowledged

Let (e_1=\hat z_{ij}-z_{ij}), (e_2=\hat z_{ji}-z_{ji}), (e_m=(e_1+e_2)/2), and (e_d=e_1-e_2). Under squared loss,

\[
\|e_1\|^2+\|e_2\|^2
=2\|e_m\|^2+\tfrac12\|e_d\|^2.
\]

The auxiliary loss therefore increases the weight on the antisymmetric component of paired rollout error. It adds no label information beyond the same branch endpoints. A reviewer would be justified in describing it as structured reweighting of multi-step MSE.

The contribution is viable only if this component is a previously underdiagnosed bottleneck in latent planners, if it is associated with maneuver failures predicted by geometric control, and if targeted supervision improves on ordinary reweighting and overshooting under matched data and compute. A small gain from additional data is insufficient novelty.

## From order fidelity to planner decisions

For the squared latent goal cost (C(z,g)=\|z-g\|^2), define

\[
m=(z_{ij}+z_{ji})/2,\qquad d=z_{ij}-z_{ji}.
\]

Then, without a smooth-dynamics assumption,

\[
C(z_{ij},g)-C(z_{ji},g)=2(m-g)^\top d.
\]

Separating two futures is insufficient: the direction of (d) relative to the goal determines which order is preferable. If (\|\hat m-m\|\le\eta), (\|\hat d-d\|\le\epsilon), (\|m-g\|\le R), and (\|d\|\le D), Cauchy–Schwarz gives

\[
|\widehat{\Delta C}-\Delta C|
\le 2(R\epsilon+D\eta+\eta\epsilon).
\]

When the true cost margin exceeds this bound, the ranking of the pair is preserved. This is a local bound for two candidates under the same frozen latent metric. It does not guarantee physical-reward ranking or whole-episode MPC success. Physical outcomes must test metric sufficiency. The bound also explains why prediction loss remains necessary: ORDER controls (epsilon), while mean error (eta) also affects ranking.

## Completed analytic sanity check

The [sanity-check script](scripts/sanity_check.py) implements a true unicycle, (dot x=v\cos\theta,dot y=v\sin\theta,dot\theta=\omega), and a hand-constructed predictor that uses a fixed translation direction. It still distinguishes rotation from translation but makes them commute. It is not a learned model.

From the zero state,

\[
s_{RT}=(h\cos h,h\sin h,h),\qquad s_{TR}=(h,0,h).
\]

| (h) | Mean squared endpoint norm error | (\|d-\hat d\|/h^2) |
|---|---:|---:|
| 0.20 | 7.9734×10⁻⁴ | 0.99833 |
| 0.10 | 4.9958×10⁻⁵ | 0.99958 |
| 0.05 | 3.1243×10⁻⁶ | 0.99990 |

Halving (h) reduces endpoint error by approximately 16×, while normalized order error remains near one. This establishes the constructed example and its (h^4) scaling; it does not establish prevalence in JEPAs or any planning gain. The script also checks the cost-gap identity, bound, and paired-loss decomposition over 10,000 random cases. Maximum numerical discrepancy is approximately (2.84\times10^{-14}), with no observed bound violations. Numerical checks do not replace the proof. The executable writes `outputs/sanity/sanity_results.json`.

## Benchmarks and alternative explanations

The original benchmark candidates are not certified as suitable. The implementation order is now official PushT reproduction and audit, a controlled PushT intervention if the audit passes, then unicycle diagnostics and model transfer. Three-dimensional navigation is deferred.

| Setting | Scientific role | Required measurements |
|---|---|---|
| Rendered unicycle with observable pose | Smooth diagnostic with known controllable directions | Order vector, local bracket direction, candidate ranking, and maneuver completion |
| Same renderer with holonomic x/y translation | Negative control preserving visual difficulty while changing dynamics | Correct near-zero signal; smaller maneuver-specific benefit after baseline calibration |
| 3D differential-drive navigation across layouts | Deferred external-validity test | Closed-loop success, collisions, final pose, and matched planning budget |
| PushT with the benchmark action convention | Finite order-effect stress test under contact | Branch error, physical score, and fixed-candidate regret; no claim that contact is a smooth Lie flow |

Unicycle and 3D navigation share a kinematic structure and cannot be presented as independent dynamics families. PushT broadens the scope only if object-level order effects exist. Otherwise, the claim should remain about nonholonomic visual planning or the project should stop. Use paired starts and goals, matched candidate seeds where possible, identical horizons, optimizer iterations, model-evaluation budgets, and action bounds. A simulator scorer on the same candidates separates search coverage from ranking error.

Six experiments should be fixed before large training:

| Experiment | Question | Design and falsification criterion |
|---|---|---|
| E1 — Failure audit | Does a correctly trained baseline misrepresent order effects? | Measure held-out branch effects. Stop if error is below noise or negligible relative to task margins. |
| E2 — Planning relevance | Does this error matter beyond MSE and action decodability? | Evaluate identical candidates; stratify by error, horizon, coverage, and maneuver requirement. Correlation alone is insufficient. |
| E3 — Controlled intervention | Does the loss repair the order component? | Match data, architecture, and updates; include ordinary multi-step, displacement-weighted, and random-pair controls. |
| E4 — Candidate mechanism | Does it correct decisions in the predicted direction? | Measure margins, high-margin inversions, and regret under frozen latent cost and true physical outcomes. |
| E5 — Closed loop | Does improved scoring improve behavior? | Keep CEM/MPC fixed; report task score, success, collisions, compute, and latency. |
| E6 — Boundary | Does the effect vary as predicted? | Compare direct travel, maneuvers, commuting controls, duration/noise sweeps, and unseen compositions. |

Register predictions in advance: gains should be larger when coordinated actions matter; signed-vector matching should beat norm-only matching when goals distinguish direction; very small (h) should be unreliable under noise. Improvement need not grow with horizon because errors outside trained compositions can accumulate. On commuting controls, maneuver-specific gains should shrink after the baseline predicts the correct zero effect, although regularization may still remove spurious interactions.

## Priority baselines, metrics, and statistics

The core baselines are DINO-WM on ordinary data; DINO-WM on all branch data with matched multi-step prediction; motion- or displacement-weighted prediction; generic pair-difference matching; inverse/LDAD-style action supervision; and rollout separation. Compatible Temporal Straightening and bilinear or control-affine dynamics are later controls. Any adaptation must be named as such unless its original architecture is reproduced. Compare norm-only and signed ORDER, lambda, and duration.

Report normalized order-vector error, angular error only above the true-effect noise floor, amplitude ratio, false effects in commuting cases, one- and multi-step feature error, action decoding with a fresh probe, fixed-candidate regret, and closed-loop physical outcomes. Keep normalization fixed across models. Raw latent MSE is not comparable across encoders with different scales; shrinking feature norms does not demonstrate repaired dynamics. Simulator state is allowed for audits and labeled privileged baselines, but not primary image/action-only training.

Pairs from one anchor are dependent. Report variation by training seed and environment and use paired bootstrap resampling at the episode or anchor level. Three seeds are a screening design. A full study should target at least five and determine evaluation-set size from pilot variance and power.

## Gated pilot

Stage A reproduces the official PushT checkpoint/configuration and audits reset behavior, action grouping, observation history, the frozen representation, and true-outcome scoring on a qualification split. ORDER is not trained. If true dynamics, cost, and search do not yield useful decisions, the pipeline cannot test a predictor-only claim.

Stage B starts only if Stage A finds remediable order-related physical regret. Compare ordinary multi-step branch MSE, ORDER, and generic reweighting on identical branches, checkpoint, and update budget, using three training seeds. Fix the minimum physically relevant effect and final evaluation size from qualification variance before opening the final test.

Stage C evaluates prespecified data/capacity curves, state- and image-based unicycle diagnostics, and model transfer where feasible. Toy-only success cannot support a broad claim. Tasks and horizons cannot be chosen by observing ORDER test gains.

Stop or narrow the project if a strong baseline has no failure, branch MSE fixes everything, order metrics improve without physical-ranking gains, improvements arise from latent collapse or rescaling, privileged targets become necessary, a generic pair loss matches ORDER, or gains require method-only macro-actions or compute.

If the pilot passes, a full study may require roughly 6–10 weeks, depending on infrastructure and reproducibility. Start with cached frozen features and modest predictors; measure throughput and memory before estimating GPU-hours. The current review does not support a precise total-compute estimate or foundation-model pretraining.

## Conditional paper claim

> Latent world models can retain accurate short-horizon predictions and decodable actions while misrepresenting the effects of action order. On visual control tasks that require coordinated maneuvers, explicitly calibrating these effects improves candidate evaluation and closed-loop planning under matched data and compute.

This is a proposed claim, not a result. The publishable contribution would be evidence that prediction accuracy, action decodability, and order fidelity can separate, plus a controlled test of their planning consequences. The auxiliary loss is only the intervention. If the separation does not survive the strongest matched baselines, this should not be written as a top-conference method paper.
