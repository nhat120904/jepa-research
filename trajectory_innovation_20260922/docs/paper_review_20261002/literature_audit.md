# CTA literature verification — 2 October 2026

Scope: primary-source verification and positioning for the developmental CTA manuscript. Reviewed `paper_cvpr/main.bib` and `sec/2_related.tex`; no manuscript files edited and no compute jobs submitted. CTA implementation facts below are supplied by the parent task: one segment code, encoder and reader observe context, no goal input to code/predictor, action-blind reader, and deployment uses 48 continuous expected-FSQ scalars. Literature findings do not establish CTA's conditional coding, intermediate-event retention, or cross-query reuse benefits.

## Positioning comparison

These are architectural distinctions, not comparative performance claims.

| Work | What is predicted or searched | Evaluation interface | Narrow CTA distinction |
|---|---|---|---|
| DINO-WM / V-JEPA 2-AC | Future spatial feature maps from frozen visual encoders; V-JEPA 2-AC autoregressively predicts next-frame features | Optimize actions toward image-goal features | CTA learns a single compressed segment target with reader supervision, rather than retaining each future feature map. Task independent prediction and image-goal planning are already present. [DINO-WM](https://proceedings.mlr.press/v267/zhou25t.html), [V-JEPA 2 method](https://arxiv.org/html/2506.09985v1#S3) |
| CompACT | Image representations of 8 or 16 discrete tokens; per-step latent world-model rollout | Navigation costs on decoded images or latent distance | CTA changes temporal unit and training target: one context-conditioned segment code and a learned reader. Compact tokens and planning/compute tradeoffs are prior art. [CompACT method](https://arxiv.org/html/2603.05438v1#S3) |
| GPC | Action-conditioned future states or images from policy proposals; vision model uses recursive conditional diffusion | GPC-RANK selects with learned or VLM rewards; GPC-OPT refines actions | Same candidate-based planning recipe; CTA substitutes a compact learned segment representation for predicted observations. [GPC method](https://arxiv.org/html/2502.00622v4#S3) |
| DreamSteer | Frozen DINOv2 feature trajectories, decoded to images; VLA proposals plus primitives | Language-conditioned VLAC scores visual progress along rollout | Goal/input independence of dynamics plus query-conditioned evaluation is not unique to CTA. CTA's reader consumes one learned segment code and context. [DreamSteer method](https://arxiv.org/html/2607.02865v1#S3) |
| Robot Critics | Action-conditioned generated visual consequences of policy candidates | VLM critic trained on paired success/failure progress comparisons | Learned fine-grained progress supervision and prediction-based policy steering are prior art; CTA jointly shapes a compact prediction target. [Author project](https://robocritic.cs.columbia.edu/) |
| V-GPS | Direct action reranking with an offline-RL value function | Value-guided proposal selection | Explicit code prediction separates CTA's dynamics interface from direct action scoring. Do not describe V-GPS as merely task-progress regression. [PMLR](https://proceedings.mlr.press/v270/nakamoto25a.html) |
| TAP | State-conditioned discrete codes of full trajectories; planner searches over latent actions and decoder reconstructs trajectories | Predicted cumulative reward and trajectory prior | TAP already gives conditional compact trajectory codes. CTA predicts a code from a supplied action chunk and withholds that action chunk from its reader. [TAP](https://arxiv.org/abs/2208.10291) |
| Delta-IRIS | Context-aware discrete stochastic deltas between steps; autoregressive transformer with continuous state summaries | Imagined RL | Context-aware coding is prior art; CTA uses a multi-step code and reader/reconstruction training. The benefit of conditioning in CTA needs an isolated result. [PMLR](https://proceedings.mlr.press/v235/micheli24a.html) |
| Value equivalence / VSRL | Models that preserve relevant Bellman updates; VSRL compresses the environment using a value-based rate-distortion criterion | Value-based planning | Decision-aware compression is the motivation, not new. CTA instantiates a future-segment bottleneck for candidate scoring; it does not establish a value-equivalence theorem. [VE](https://proceedings.neurips.cc/paper_files/paper/2020/hash/3bb585ea00014b0e3ebe4c6dd165a358-Abstract.html), [VSRL](https://proceedings.neurips.cc/paper_files/paper/2022/hash/3b18d368150474ac6fc9bb665d3eb3da-Abstract-Conference.html) |

## Concrete corrections and unsupported distinctions in current related work

- Expand **GPC as Generative Predictive Control**, not Goal Predictive Control. The paper's current title replaces its earlier title. [Author page](https://computationalrobotics.seas.harvard.edu/GPC/)
- FOREWARN's official RSS author is **Thomas Tian**, not Ran Tian. Its latent world model predicts futures, then its aligned VLM reasons about them. Existing prose is broadly fair but should avoid implying its scorer only sees raw actions. [RSS paper record](https://www.roboticsproceedings.org/rss21/p076.html)
- Name the visual encoders separately: DINO-WM uses frozen **DINOv2** features, while V-JEPA 2-AC uses its frozen **V-JEPA 2** encoder. The shared sentence followed by a DINOv2 citation currently risks suggesting both use DINOv2. [DINO-WM](https://proceedings.mlr.press/v267/zhou25t.html), [V-JEPA 2-AC training](https://arxiv.org/html/2506.09985v1#S3)
- DynaGuide is active gradient guidance of the diffusion denoising process, using a separate latent dynamics model; describing it as proposal ranking omits its central mechanism. Its official proceedings title spells **Polices**, while the author BibTeX spells **Policies**; use one documented convention. [NeurIPS](https://proceedings.neurips.cc/paper_files/paper/2025/hash/3ec6c6fc9065aa57785eb05dffe7c3db-Abstract-Conference.html), [author page](https://dynaguide.github.io/)
- RoboMonkey's CoRL 2025 status and authors are correct; official PMLR page gives 3200–3217, volume 305. It verifies action proposals directly; the current no-world-model distinction is reasonable for deployment. [PMLR](https://proceedings.mlr.press/v305/kwok25a.html)
- GCQ is a real NeurIPS 2025 paper with an action-conditioned codebook that compresses observation-action sequences in space and time and supports goal-directed planning. Do not subsume it under a blanket frozen observation encoder distinction. [NeurIPS](https://proceedings.nips.cc/paper_files/paper/2025/hash/f18d5002b0c1e18d371805ea363d430b-Abstract-Conference.html)
- Jumpy world models are a 2026 preprint that predict state occupancies induced by policies across timescales and use them to value policy sequences. Describe that concrete object instead of claiming all extended models predict without reference to history; their initial conditioning already contains observed state. [arXiv](https://arxiv.org/abs/2602.19634)
- Delete “In all of these models ... independently of the decision it will serve.” TD-MPC2 learns an implicit control model, and value-aware modeling explicitly trains with a decision-informed loss. Restrict the comparison to frozen-encoder visual prediction methods. [TD-MPC2](https://openreview.net/pdf?id=FzpfPa6unv), [VAML](https://proceedings.mlr.press/v54/farahmand17a.html)
- Delete the claim that other models' source is not an unexecuted future: action-conditioned world models and value-equivalent transition models also model action consequences before execution. Use CTA's segment-level interface as the distinction. [GPC](https://arxiv.org/html/2502.00622v4), [VE](https://proceedings.neurips.cc/paper_files/paper/2020/hash/3bb585ea00014b0e3ebe4c6dd165a358-Abstract.html)
- Action-blind outcome evaluation is a useful CTA constraint, but is not an isolated novelty claim: GPC's reward model is applied to predicted future state information, and DreamSteer's VLAC scores predicted visual observations with instructions rather than directly consuming candidate actions. The narrower contribution is learning and predicting the compact segment target within that interface. [GPC scoring](https://arxiv.org/html/2502.00622v4#S3), [DreamSteer scoring](https://arxiv.org/html/2607.02865v1#S3)

## Recommended main-text claim boundaries

1. Main contribution wording: **“CTA studies a compact prediction target for candidate-based visual planning. It encodes an observed future segment jointly with its context, trains a predictor from context and a proposed action chunk, and scores the predicted code with a goal-conditioned reader that has no access to the proposed actions.”** This is an implementation description, without an originality claim.
2. **“Our learned deployment interface comprises 48 continuous scalars obtained as expectations over finite scalar quantization levels.”** FSQ itself quantizes scalars to finite values. A continuous expectation is not a realized discrete token or a transmitted bitrate; do not call the deployed code 48 discrete symbols, claim nominal FSQ bits, or compare it directly to CompACT's discrete token counts as storage equivalence. [FSQ](https://proceedings.iclr.cc/paper_files/paper/2024/hash/e2dd53601de57c773343a7cdf09fae1c-Abstract-Conference.html)
3. **“The code and predictor do not take the goal image as input; a shared reader receives the goal at scoring time.”** Prefer this precise input-level statement over “task-agnostic,” “for any goal,” or demonstrated arbitrary query reuse. A reader supervised on goals can still shape the code toward those training goals.
4. **“Reader and reconstruction losses encourage preservation of decision-relevant and visual information.”** An auxiliary reconstruction term does not guarantee goal generalization, sufficient statistics, or residual-only coding.
5. **“The encoder can use context when representing the future.”** Do not strengthen this to “spends capacity only on information history leaves open,” or attribute results to conditioning without a matched conditioning ablation. Delta-IRIS already provides a context-aware precedent. [Delta-IRIS](https://proceedings.mlr.press/v235/micheli24a.html)
6. **“The training target includes a segment's intermediate observations.”** Temporal supervision is an architecture fact; retaining decision-critical intermediate events is an empirical claim. Keep endpoint-control results valid and describe event retention as an unisolated property.
7. Quality/compute conclusion should refer to measured latency and matched learned closed-loop results, with horizon, candidates, data, and precision stated. Naming baseline variants as **matched endpoint/per-step representation controls inspired by GPC** avoids implying faithful reproduction of published GPC, DINO-WM, or CompACT systems.

No added baselines or speculative sweeps are required by this literature review. The central current comparison is the measured quality/compute effect of the learned segment target under a matched planner, with the structural properties stated as design choices until isolated by evidence.
